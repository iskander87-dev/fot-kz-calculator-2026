# Калькулятор ФОТ для Казахстана — 2026

Публичный адаптивный калькулятор для предварительной оценки зарплаты и полной стоимости иностранного сотрудника — гражданина России, работающего в Казахстане.

Все вычисления выполняются непосредственно в браузере. Введённые суммы не отправляются на сервер и не сохраняются.

## Открыть калькулятор

**[Перейти в калькулятор](https://fot-kz-calculator-2026.ponomarev-ao.chatgpt.site)** — вход без регистрации и авторизации.

## Как пользоваться

1. Введите начисленную Gross-зарплату в тенге.
2. Проверьте статус налогового резидентства Казахстана.
3. Укажите налогооблагаемый доход с начала года до текущего месяца. Это поле нужно для применения годовой шкалы ИПН 10% / 15%. Для первого месяца его можно оставить пустым.
4. Включите отметку «Сотрудник родился до 01.01.1975», если она применима.
5. Результаты обновятся автоматически: сверху показаны Net и полная стоимость, ниже — подробная расшифровка.

## Что рассчитывается

Параметры 2026 года:

- МРП — 4 325 ₸;
- МЗП — 85 000 ₸;
- базовый налоговый вычет — до 30 МРП, или 129 750 ₸ в месяц;
- годовой порог ИПН — 8 500 МРП, или 36 762 500 ₸ налогооблагаемого дохода.

### Удержания сотрудника

- ОПВ: `min(Gross, 50 МЗП) × 10%`;
- ВОСМС: `min(Gross, 20 МЗП) × 2%`;
- база ИПН резидента: `max(0, Gross − ОПВ − ВОСМС − применённый вычет)`;
- база ИПН нерезидента: `Gross` без налоговых вычетов;
- ИПН: 10% в пределах годового порога 8 500 МРП и 15% с превышения;
- Net: `Gross − ОПВ − ВОСМС − ИПН`.

Применённый вычет не может быть больше дохода после ОПВ и ВОСМС.

### Начисления работодателя

- ОПВР: `3,5%` с базы от 1 до 50 МЗП; для родившихся до 01.01.1975 — 0 ₸;
- социальные отчисления: `min(Gross, 7 МЗП) × 5%`;
- ОСМС работодателя: `min(Gross, 40 МЗП) × 3%`;
- социальный налог: `(Gross − ОПВ − ВОСМС) × 6%`;
- полная стоимость: `Gross + ОПВР + социальные отчисления + ОСМС работодателя + социальный налог`.

Каждый платёж округляется до целого тенге до сложения итоговой суммы.

## Контрольный пример

Для налогового резидента РК с Gross 1 000 000 ₸, нулевым доходом до текущего месяца и датой рождения после 01.01.1975:

| Показатель                          |       Сумма |
| ----------------------------------- | ----------: |
| ОПВ                                 |   100 000 ₸ |
| ВОСМС                               |    20 000 ₸ |
| Применённый вычет                   |   129 750 ₸ |
| ИПН                                 |    75 025 ₸ |
| Net                                 |   804 975 ₸ |
| Начисления работодателя сверх Gross |   147 550 ₸ |
| Полная стоимость работодателю       | 1 147 550 ₸ |

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, указанный в терминале. Обычно это `http://localhost:3000`.

## Проверка

```bash
npm test
npm run lint
npm run build
```

Автоматические тесты проверяют контрольный пример, резидента и нерезидента, освобождение от ОПВР, низкую зарплату, предельные базы, прогрессивный ИПН и согласованность округления.

## Ограничения

Калькулятор предназначен для предварительной оценки. Он не учитывает индивидуальные льготы, дополнительные вычеты, особенности конкретного договора, неполный месяц и все специальные категории работников. Для начисления зарплаты и налоговой отчётности используйте расчёт бухгалтера или налогового консультанта.
