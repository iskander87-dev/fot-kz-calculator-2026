# Калькулятор ФОТ для Казахстана — 2026

Небольшой адаптивный веб-калькулятор для оценки заработной платы и полной стоимости иностранного сотрудника — гражданина России, работающего в Казахстане.

Сайт работает без регистрации и авторизации. Все вычисления выполняются непосредственно в браузере; введённая сумма никуда не отправляется и не сохраняется.

## Возможности

- ввод Gross-зарплаты в тенге с автоматическим форматированием;
- выбор статуса налогового резидентства Казахстана;
- отдельный режим для сотрудника, родившегося до 01.01.1975;
- расчёт удержаний сотрудника, суммы Net и начислений работодателя;
- отображение полной стоимости сотрудника для работодателя;
- адаптивный интерфейс для компьютеров и мобильных устройств.

## Логика расчёта

В расчёте используются показатели 2026 года:

- МРП — 4 325 ₸;
- базовый налоговый вычет — 30 МРП, или 129 750 ₸ в месяц;
- МЗП — 85 000 ₸;
- максимальная база социальных отчислений — 7 МЗП, или 595 000 ₸.

### Удержания сотрудника

- ОПВ: `Gross × 10%`;
- ВОСМС: `Gross × 2%`;
- ИПН резидента: `max(0, Gross − ОПВ − ВОСМС − 30 МРП) × 10%`;
- ИПН нерезидента: `Gross × 10%` без налоговых вычетов;
- Net: `Gross − ОПВ − ВОСМС − ИПН`.

### Начисления работодателя

- ОПВР: `Gross × 3,5%`; для родившихся до 01.01.1975 — 0 ₸;
- социальные отчисления: `min(Gross, 7 МЗП) × 5%`;
- ОСМС работодателя: `Gross × 3%`;
- социальный налог: `(Gross − ОПВ − ВОСМС) × 6%`;
- полная стоимость: `Gross + ОПВР + социальные отчисления + ОСМС работодателя + социальный налог`.

## Локальный запуск

Требуется Node.js версии 22.13 или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, указанный в терминале. Обычно это `http://localhost:3000`.

## Проверка и сборка

```bash
npm run build
```

## Важно

Калькулятор предназначен для предварительной оценки. Он не учитывает индивидуальные льготы, дополнительные вычеты, особенности конкретного договора и возможные изменения законодательства. Для расчёта заработной платы и налоговой отчётности используйте данные бухгалтера или налогового консультанта.
